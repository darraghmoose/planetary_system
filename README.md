# N-Body Planetary System

This repository contains the code used in PHY3009 computing assignment

## Structured work
Parts 1-2 are addressed in earth_and_stationary_sun.py. This code Assumes the sun is unaffected by the pull of the Earth and iteratively updates the position of the Earth using the Runge-Kutta method. 
The intial radius and velocity of the planet are set to match a perfectly circular version of Earth's orbit.  

Part 3 is adressed in arbitrary_stationary_sun.py. This programme is very similar to earth_and_stationary_sun.py but considers an earth like body orbiting our Sun at a radius calculated using my student number.
